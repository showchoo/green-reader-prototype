# Green Reader Prototype v0.1

FCNT arrows We2 M07（ARCore Depth対応）を想定した、ゴルフグリーン解析の試作Androidアプリです。

## 今回実装したもの

- ARCore Depthで周囲の深度点を連続収集
- 画面タップで「ボール位置」「カップ位置」を指定
- ボール〜カップ間の点群だけを自動抽出
- パットライン方向を8区間に分け、各区間の
  - 上り/下り勾配（%）
  - 左右勾配（%）
  - 高さ変化
  を自動推定
- 途中で勾配が変わる様子を簡易プロファイルとして表示
- カメラ画像のテクスチャ方向から「芝目の軸」を実験的に推定
- Stimp値を入力して、傾斜から狙い量・実質距離を試算（**実験機能**）

## 重要な制約

### 1. M07のDepthは測量機ではありません
ゴルフグリーンで重要な1〜3%程度の微小傾斜を、ARCore Depthだけで安定して測れるかは実機テストが必要です。多数フレームの平均化や外れ値除去を今後追加する想定です。

### 2. 芝目の「方向」はまだ確定できません
v0.1は芝の画像テクスチャから主軸（例: 35°/215°の軸）を推定します。単眼画像では順目・逆目の向きを照明条件から安定判定しにくいため、現段階では「軸＋信頼度」までです。

### 3. 推奨狙い量は未キャリブレーション
「左○cm」表示は物理モデルの試作品です。実際の芝抵抗・刈高・湿度・ボール速度で大きく変わるため、現状は練習用の参考値です。

## 使い方

1. Android Studioでプロジェクトを開く
2. M07をUSBデバッグ接続する
3. 実行してカメラ権限を許可
4. 端末を少し動かしてARCoreを安定させる
5. `ボール` → 画面上のボール位置をタップ
6. `カップ` → 画面上のカップ位置をタップ
7. `スキャン` を押して、ボール〜カップ周辺をゆっくり左右に振りながら撮る
8. もう一度 `スキャン` または `解析` を押す
9. 下部のプロファイルと勾配値を確認
10. 芝目は `芝目軸解析` を押す

## スキャンのコツ

- スマホは腰〜胸の高さより、グリーン面に対して斜め30〜50°程度で向ける
- 1地点で止まらず、ゆっくり20〜50cmほど横移動する
- 逆光を避ける
- 3〜6m程度から試す
- 長いパットはボール側からカップ側へ移動しながら複数角度で取る

## ビルド要件

- Android Studio（JDK 17）
- Android SDK 35
- Android 8.0以上
- Google Play Services for AR
- ARCore Depth対応端末

依存: `com.google.ar:core:1.54.0`

## 次に改善したいもの

1. フレーム間の点群融合（同一点の中央値/ロバスト平均）
2. RANSACで芝面だけを抽出
3. 1%未満の傾斜を見分けるノイズ評価画面
4. グリーン全体の2Dヒートマップ
5. AR上に傾斜矢印を直接重ねる
6. 芝目の順/逆方向推定（複数方向撮影＋照度変化）
7. 実際の1m/3mパットによる日別キャリブレーション
8. キャリブレーション後のボール軌道シミュレーション

## ルール/マナー

競技ではグリーン読み補助機器・電子情報の使用が制限されることがあります。またグリーン面に端末を置く使い方は想定していません。練習ラウンドでもコースのルールと進行を優先してください。
