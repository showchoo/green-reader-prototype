The **median range of a whole depth image** staying within 5mm is NOT evidence of any individual floor point measured to 5mm precision: many pixels can systematically move or shift while an aggregate statistic stays similar. The changing pixel values can reflect hand motion or observing different physical spots (the device was held), as well as range jitter; **do not present the 10mm span as calibrated sensor noise**.

Android's official `ImageFormat.DEPTH16` confidence encoding is unusual: **code 0 = 100%, code 1 = 0%, code 2 = 1/7, code 3 = 2/7, ... code 7 = 6/7**. All observed nonzero range samples have codes 2–4. No observed sample qualifies as >=50% confidence. Source: https://developer.android.com/reference/android/graphics/ImageFormat

## Geometry feasibility (offline exploratory only)

- Intrinsics ~535.93/535.49px at 640×480, distortion and lens-pose quaternion available.
- A gravity-aligned, calibrated radial-range 3D plane fitting **experiment** on selected image regions yielded widely differing plane normals: left-of-image fit ~6–8° from gravity, right-of-image ~3.0–3.35°, and a wider central ROI occasionally ~0.5–3.4°. This could reflect **different physical surfaces, segmentation choices, calibration, or unstable low-confidence range**; the recorded depth stream has NO matching color/semantic labels. These are not proven measurements of the same section of floor or a physical green slope.
- A relatively low single-region fit residual (typically 6–9mm in the illustrative RANSAC) does **not** determine that region is horizontal or that its estimated normal is unbiased. Gravity variation ~0.66° during the handheld capture is also material compared with the **0.286° inclination-only budget** for 0.5 percentage-point slope error, although motion is not the same as calibrated angle error.
- Camera2 lens-pose reference was PRIMARY_CAMERA (=0), not an independently surveyed gyroscope-to-camera transform. Official Camera2 documentation defines the quaternion in Android sensor coordinates, but external calibration is still required for sub-degree grade claims: https://developer.android.com/reference/android/hardware/camera2/CameraCharacteristics
